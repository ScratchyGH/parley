Parley

Chat, call and hang out. As an app.

Install Parley on your device. It opens in its own window, uses almost no storage and updates itself.

Use in browser instead

iPhone and iPad

Open this page in Safari, tap Share, then Add to Home Screen.

Android

Tap Install. Parley is added to your app drawer.

Windows

Install from Edge or Chrome. It gets its own taskbar icon and window.

Mac

Install from Chrome or Edge, or use File, Add to Dock in Safari.

Linux

Install from Chrome, Edge or Brave.

Installed Parley is the full app. Nothing is stored beyond a small cache.
